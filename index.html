07 / Assessment

What Went Well & Future Work

// WHAT WENT WELL
⚡ FULL AUTOMATION

One phishing click triggers the entire kill chain — credential capture, file locking, portal shutdown — all automatically via watcher.sh.

🔀 LEVEL 2 LATERAL MOVEMENT

Real pivot from nurse workstation to hospital server using only stolen SMB credentials. No additional exploits needed.

🛡️ REAL SIEM DETECTION

Wazuh detected every phase of the attack in real time. 18 custom rules + CYBERLAB dashboard — all 9 panels fired.

💀 TWO-MACHINE IMPACT

Both nurse workstation AND hospital server locked simultaneously — showing true ransomware network-wide scale.

// OPPORTUNITIES FOR IMPROVEMENT
Level 3 — Network-Wide Propagation

Nmap scan entire subnet, auto-target every Windows machine found — true ransomware worm behavior.

Double Extortion

Exfiltrate patient records to Kali BEFORE locking — then threaten to publish. Mirrors LockBit and BlackCat real-world tactics.

Anti-Forensics Simulation

Stop Wazuh agent before encrypting to demonstrate attackers covering their tracks. Show agent-gone-silent detection.

Email Delivery via Postfix

Deliver phishing email to actual Outlook inbox using a local mail server — more realistic than opening a browser page.

Behavioral Analytics

Detect unusual user patterns before the attack completes — proactive threat hunting vs reactive alerting.
