07 / Assessment

  
What Went Well & Opportunities for Improvement

  

    

      
// WHAT WENT WELL

      

        

          
⚡ FULL AUTOMATION

          
One phishing click triggers entire kill chain — cred capture, file locking, portal shutdown — via watcher.sh.

        

        

          
🔀 LEVEL 2 LATERAL MOVEMENT

          
Real pivot from nurse workstation to hospital server using only stolen SMB credentials.

        

        

          
🛡️ REAL SIEM DETECTION

          
Wazuh detected every phase in real time. 18 custom rules. All 9 dashboard panels fired.

        

        

          
💀 TWO-MACHINE IMPACT

          
Both nurse WS and hospital server locked simultaneously — true ransomware network scale.

        

        

          
🌐 GITHUB PAGES PRESENTATION

          
This presentation — particle network, glitch effects, self-typing terminals — zero dependencies.

        

      

    

    

      
// OPPORTUNITIES FOR IMPROVEMENT

      

        

          
Level 3 — Network-Wide Propagation

          
Nmap scan entire subnet, auto-target every Windows machine — true ransomware worm behavior.

        

        

          
Double Extortion

          
Exfiltrate records BEFORE locking — then threaten to publish. LockBit / BlackCat tactics.

        

        

          
Anti-Forensics Simulation

          
Stop Wazuh agent before encrypting — show attackers covering their tracks.

        

        

          
Email via Postfix

          
Deliver phishing to actual Outlook inbox — more realistic than a browser page.

        

        

          
Behavioral Analytics

          
Detect unusual user patterns proactively before the attack completes.

        

      

    

  







  

  
08 / Conclusion

  
Key Takeaways

  

    ⚠
    
A single phishing email — one nurse — compromised credentials, exfiltrated patient records, and locked down an entire hospital server in under 60 seconds. This is not hypothetical. This is exactly how real hospital ransomware attacks work.

  

  

    

      
// KEY TAKEAWAYS

      

        
1
Phishing is the #1 entry point — security awareness training is the most critical first line of defense

        
2
Credential reuse is catastrophic — one stolen set of credentials compromised the entire hospital server

        
3
Speed matters critically — from phishing click to full hospital lockdown in under 60 seconds

        
4
Detection is absolutely possible — Wazuh fired 7 alert categories covering every phase of the attack

        
5
Defense in depth works — MFA, email filtering, and network segmentation each would have stopped this
