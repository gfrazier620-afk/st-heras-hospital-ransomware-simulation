Introduction

The Problem

Hospitals are the #1 target for ransomware attacks. In 2024, over 140 U.S. hospitals were hit — causing patient care disruptions, data breaches, and millions in recovery costs.

Entry point for 91% of attacks?

A single phishing email.

Our Solution

A fully automated, end-to-end hospital ransomware simulation demonstrating exactly how these attacks unfold — and how a SOC analyst detects them using Wazuh SIEM.

Story-Arc: The Attack Chain

Nicole Rivera, RN — St. Hera's Hospital, 3 West

01

Phishing Email

Nicole receives an urgent IT Security email warning her account will be suspended. She clicks the link.

02

Credential Theft

She enters her username and password. Credentials captured instantly on the attacker's machine.

03

Network Recon

Attacker scans the network. Discovers WIN-HOSPITAL-SERVER with SMB port 445 open.

04

Lateral Movement

Nicole's stolen credentials authenticate to the hospital server. Patient records accessed and stolen.

05

Ransomware Impact

Both machines locked simultaneously. Ransom note delivered. Hospital portal goes completely dark.

06

SIEM Detection

Wazuh fires 7 alert categories. SOC dashboard reconstructs the full attack chain in real time.

What Went Well & Future Work

What Went Well
⚡ Full Automation

One phishing click triggers the entire attack chain — credential capture, file locking, portal shutdown.

🔀 Level 2 Lateral Movement

Real pivot from nurse workstation to hospital server using only stolen credentials.

🛡️ Real SIEM Detection

Wazuh detected every phase of the attack in real time with 18 custom rules.

💀 Two-Machine Impact

Both nurse workstation AND hospital server locked simultaneously — true ransomware scale.

Opportunities for Improvement
Level 3 — Network-Wide Propagation

Scan entire network and lock every Windows machine — true ransomware spread.

Double Extortion

Exfiltrate patient records BEFORE locking — mirrors LockBit and BlackCat tactics.

Anti-Forensics Simulation

Stop Wazuh agent before encrypting — show attackers covering their tracks.

Email Delivery via Postfix

Deliver phishing email to actual Outlook inbox instead of a browser page.

Behavioral Analytics

Detect unusual user patterns before the attack completes.

Conclusion

A single phishing email — sent to one nurse — was enough to compromise credentials, access patient records, and lock down an entire hospital server automatically. This is not hypothetical. This is exactly how real hospital ransomware attacks work.
Key Takeaways
1

Phishing is the #1 ransomware entry point — employee security awareness training is critical

2

Credential reuse is dangerous — one stolen set of credentials accessed the entire hospital server

3

Speed matters — full attack chain from credential theft to hospital lockdown in under 60 seconds

4

Detection is possible — Wazuh fired 7 alert categories giving a SOC analyst everything needed to reconstruct the attack

5

Defense in depth works — MFA, email filtering, and network segmentation would have stopped this at multiple points
